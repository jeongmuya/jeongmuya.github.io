# Tendon10

Tendon10 is a minimal finger training timer for climbers.

It helps climbers follow a simple 10-minute routine:

- 10 seconds of work
- 50 seconds of rest
- 10 total sets

Training history is stored locally on the device. The app does not require sign-in or server synchronization.
